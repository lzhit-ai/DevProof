# 工作台壳层 UI 优化设计

## 目标

将 AI-CodeReview 工作台调整为沉浸式的双栏工作区：左侧导航承担全局切换与用户入口，右侧页面自身承担标题与内容展示。此次只调整前端视觉布局，不改变路由、模拟数据或业务接口。

## 布局

- `WorkbenchLayout` 使用固定宽度的左侧栏和可伸缩的右侧内容区。
- 左侧栏顶部保留产品标识，中部为导航，底部固定演示用户卡片。
- 演示用户显示圆形头像、姓名“张伟”、角色“交付核验负责人”和一个更多操作按钮；不接入认证或用户 API。
- 原 `global-topbar` 不再表现为独立白色顶部条。它与主内容背景融为同一层，仅保留页面上下文所需的区域。
- 每个右侧页面在其内容区左上角展示页面标题和说明；标题字号控制在 20--22px，避免压过内容。

## 导航视觉

- 导航链接使用整行按钮布局，图标与文字沿交叉轴垂直居中。
- 移除浏览器默认链接下划线；颜色从父元素继承。
- 当前路由使用低饱和背景、强调色文字和左侧细标记表示，不依赖下划线。
- 悬停、键盘聚焦与选中态有可区分的视觉反馈，且不改变布局尺寸。

## 修改范围

- `frontend/src/layouts/WorkbenchLayout.vue`：加入固定演示用户区域，整理壳层结构。
- `frontend/src/pages/*.vue`：将页面标题保持在右侧页面内容区左上角，并使用统一标题样式。
- `frontend/src/styles.css`：实现壳层、导航、用户卡片、标题和响应式样式。

## 不在范围内

- 不新增或修改后端接口、认证、路由与模拟数据。
- 不替换现有页面的业务内容或 Notebook 核验流程。
- 不提交当前工作区已有的其他未提交文件。

## 验收标准

1. 左侧栏底部始终显示固定演示用户卡片。
2. 导航文字水平可见、垂直居中，且没有下划线。
3. 顶部栏不再以独立白条与主背景分割。
4. 每个普通右侧页面的标题出现在内容区左上角，字号比当前更小。
5. 宽度收窄时内容区不产生水平溢出，用户卡片和导航仍可访问。
